TradeCraft User Manual

TradeCraft is a unified trading research platform combining five powerful tools into one seamless interface. Backed by a live PostgreSQL market database, it connects the entire workflow from sector analysis to backtested strategy — without switching between multiple applications.

This manual covers all features available as of June 2026. As new features are added, they will be appended to the Appendix section of this document.

🔄 Sector Rotation Scanner

Analyze 11 sector ETFs for momentum acceleration. Identify leading stocks within each sector.

🔍 AI Stock Screener

Screen the S&P 1500 with technical/fundamental modes and optional multi-agent AI analysis.

⚡ QuantGen Strategy Builder

Generate, backtest, and optimize quantitative strategies with AI-assisted code generation.

📊 Markov Chain Trader

Regime-aware convergent signals using Markov-switching models plus pattern recognition.

📅 Earnings Calendar

Track upcoming earnings announcements with EPS/revenue estimates for the S&P 1500.

Getting Started

Quick Start

  1. Open the app — Navigate to the TradeCraft URL in your browser.
  2. Choose a tool — The landing page displays five tool cards. Click any card to enter that module.
  3. Sidebar navigation — Once inside a tool, use the sidebar on the left to switch between modules.
  4. Run your first scan — Try the Sector Rotation Scanner first: it requires no configuration and immediately shows sector performance.
  5. Export to QuantGen — Found an interesting stock? Export it directly to the QuantGen strategy builder for backtesting.

Navigation

The app uses a sidebar navigation pattern:

  • 6 sidebar links — Home, Sector Rotation, Stock Screener, Markov Trader, Earnings Calendar, QuantGen
  • QuantGen has sub-routes — Builder (/quantgen/build), Dashboard (/quantgen/dashboard), Library (/quantgen/library)
  • Landing page (/) is the full-width marketing dashboard — no sidebar
  • All other pages render inside the sidebar layout

Theme & Display

TradeCraft defaults to dark mode (designed for early-morning and late-night trading sessions). Toggle dark/light mode using the switch in the top-right corner.

Target display: Designed for 1440px–1728px viewports (optimized for MacBook Pro 16"). Content max-width is 1280px, centered with auto margins. Responsive down to 768px.

Dormant Giant Mode

Finds stocks that are "coiling" — exhibiting a Bollinger Squeeze with consolidation, accumulation, and relative strength — poised for explosive moves. Each candidate receives an explosiveness score (0–100).

Threshold Controls

What Matters for Each Signal

  • MFI — Money Flow Index above threshold = accumulation pressure
  • Volume Cluster — volume clustering near recent highs = institutional interest
  • RS Ratio — stock outperforming market = relative strength
  • Bandwidth % — Bollinger Band tightening = squeeze setup
Start with default thresholds for the first pass, then tighten consolidation (lower) or loosen MFI (higher) to narrow or widen the candidate pool.

Quant Strategy Mode

A flexible technical/fundamental screening engine with natural-language filter parsing.

Two-Phase Workflow

  1. Describe in plain English — Type something like: "Stocks with RSI between 40-60, ADX above 25, positive EPS growth, near 52-week highs"
  2. Click "Generate Filters from Prompt" — an LLM parses your description into structured filters
  3. Review and edit — The filter panel appears with editable controls:
    • ATH Proximity slider
    • Volume Ratio slider
    • RSI range, SMA relations, indicator cross conditions
    • Sort order (by score / volatility / volume / EPS)
    • Earnings-within-days constraint
    • Max results
  4. Run the scan — Deterministic filter engine applies your rules across the S&P 1500

Scoring System

Each stock gets a hybrid quant score (0–100) combining:

  • Base Setup Score (weighted by Scoring Split slider): trend 30% + momentum 25% + volatility 20% + volume 25%
  • Filter Match Bonus: additional points per matched filter condition

Technical Indicator Guide

The Quant Strategy screener uses the ta library with 80+ technical indicators. Click the "Technical Indicator Guide" help modal in the app for a full reference. Key column prefixes:

  • trend_sma_* — Simple Moving Averages
  • momentum_rsi — Relative Strength Index
  • trend_macd — MACD
  • volatility_bb* — Bollinger Bands
  • volume_* — Volume indicators

AI Agent Analysis

When AI Toggle is enabled, an Agno multi-agent team is spawned to analyze the screening results. Each agent has a specialized role:

  • Lead Analyst — coordinates the team
  • Technical Analyst — chart patterns and technical setup quality
  • Fundamental Analyst — EPS trends, revenue growth, valuation
  • Risk Manager — volatility, drawdown risk, sector concentration

The AI team generates a natural-language report for each candidate stock with trade rationale, key risks, and a conviction rating. Click the "AI Report" button on any result card to view the full analysis.

AI analysis uses Ollama (local LLM) by default. The model is configured via the OLLAMA_MODEL_ID environment variable. AI analysis adds approximately 30–60 seconds to the scan time depending on the number of candidates.

QuantGen Strategy Builder

Routes: /quantgen, /quantgen/build, /quantgen/dashboard, /quantgen/library

Overview

QuantGen is the quantitative strategy development environment. It combines AI-powered code generation, a full Monaco code editor, VectorBT backtesting, Walk-Forward Optimization, and a rich results dashboard.

🤖 AI Code Generation

Describe your strategy in plain English. The LLM generates Python/VectorBT code with auto-fix.

⚡ VectorBT Backtesting

Execute strategies with VectorBT's high-performance engine. Equity curves, stats, trades.

🎯 Walk-Forward Optimization

Simple grid, rolling WFO, or True WFO (1-day-at-a-time simulation). Avoid curve-fitting.

💬 AI Chat Assistant

Iterate on strategy code conversationally. "Apply Changes" one-click code updates.

Builder Workspace (/quantgen/build)

Step 1: Describe Your Strategy

Enter a plain-English strategy description:

Enter a SMA crossover strategy:
Buy when 20-day SMA crosses above 50-day SMA.
Exit when 20-day SMA crosses below 50-day SMA.
Use SPY as benchmark.

Click "Generate Strategy" to get AI-generated VectorBT Python code.

The AI code generator automatically runs a CodeVerifier that detects and fixes up to 3 common categories of errors before showing you the code. It also consults a Lessons Learned store of past fixes for recurring patterns.

Step 2: Edit in Monaco Editor

The code appears in a full Monaco editor (VS Code engine) with Python syntax highlighting. The strategy code must follow this structure:

  • Indicator definitions — define indicators using VectorBT's factory API
  • Signal logic — entry/exit conditions using .vbt.gt(), .vbt.lt(), vbt.combine_logic()
  • Parameters section — annotate parameter ranges as comments for the optimizer to auto-detect
  • Portfolio.from_signals — the final call that produces the portfolio
VectorBT comparison syntax: When writing signal logic for optimization, always use .vbt.gt(), .vbt.lt(), and vbt.combine_logic() instead of >, <, &. Standard operators work for single backtests but fail during multi-parameter optimization. Add broadcast_kwargs={'keep_pd': True} and jitted=True to Portfolio.from_signals.

Step 3: Configure & Run

Choose run mode and configure parameters:

ModeWhat it doesWhen to use
BacktestSingle run with current parameters on full date rangeQuick validation of strategy logic
OptimizeGrid search + optional Walk-Forward OptimizationFinding best parameter set

Optimization Config Panel

Control panel visible in Optimize mode:

  • Optimization mode: Simple (full-range grid), WFO (rolling/expanding windows), True WFO (1-day step)
  • Metric: total_return / sharpe / sortino / max_drawdown
  • WFO config: rolling or expanding, window count, train/test ratio, split method, date range
  • Parameter ranges: auto-extracted from # Parameters comments in code

  • Request modifications in natural language

Browse and manage saved strategies. Features:

Optimization & Walk-Forward Optimization

Simple Optimization

Grid search over all parameter combinations on the full date range. Fastest, but risks curve-fitting.

Walk-Forward Optimization (WFO)

Divides the date range into rolling windows. For each window, optimizes on the training portion and tests on the out-of-sample (OOS) portion. Choose:

  • Rolling — windows move forward, old data drops off
  • Expanding — each window adds new data to an ever-growing training set
  • Split method — ratio (e.g. 70/30) or fixed number of train/test days

True Walk-Forward Optimization

The most realistic simulation of live trading. Steps 1 day at a time:

  1. Optimize parameters on training window (past N days)
  2. Pick the best parameters from that window
  3. Generate a signal from the last day of the training window
  4. Trade the next day only (1-day position)
  5. Position state carries over between windows (like real trading)
  6. Slide the window forward by 1 day and repeat
Use True WFO when you need the most realistic backtest possible. It's slower but avoids any future leakage. Standard WFO is a good balance of speed and rigor for iterative development.

Markov Chain Trader

Route: /markov  |  API: /api/markov/*

Overview

The Markov Chain Trader is a regime-aware convergent signal system that combines two independent models to generate high-conviction BUY/HOLD/SELL signals:

  1. Statistical Jump Model — Markov-switching regression with jump penalty (prevents chattering) + GJR-GARCH(1,1,1) with Student-t for volatility regime detection
  2. Pattern Recognizer — XGBoost (fast) or LSTM (deep) classifier trained with utility-aware loss to predict BUY/HOLD/SELL

Convergence rule: A BUY signal is only emitted when both models agree and the market is in a bull/low-volatility regime. This prevents false signals during transitional or high-volatility periods.

Background Retraining

The POST /api/markov/retrain endpoint triggers background retraining:

  • XGBoost: up to 500 tickers, ~8 minutes in background
  • LSTM: up to 200 tickers, ~30 minutes — only runs in quarterly months (Jan, Apr, Jul, Oct)

Check retraining status via GET /api/markov/status.

Technical Reference

Database

TradeCraft uses two PostgreSQL databases:

  • sp1500_1d — daily OHLCV data. Individual stock tables (lowercase ticker names) with columns: Date, Open, High, Low, Close, Volume
  • sp1500_1m — minute-level data with 60-day retention (TimescaleDB drop_chunks)

Additional tables: stock_metadata (sector/industry info), stock_financials_quarterly (EPS/revenue), earnings_calendar (earnings events)

Frequently Asked Questions

Why are some features showing "Demo Mode"?

If the PostgreSQL database is not available, certain features fall back to mock data. Check the database connection status at the top of the page. Ensure PostgreSQL is running and the sp1500_1d database exists with the correct credentials.

How often is market data updated?

Daily data is refreshed each trading day. Minute data has a 60-day rolling retention window. Data is ingested via an external ETL pipeline and stored in the TimescaleDB-backed PostgreSQL instance.

Can I use TradeCraft without AI features?

Yes. The AI Stock Screener has an AI Toggle that disables multi-agent analysis. QuantGen can run manually written strategies without the code generator. The AI features require Ollama with a compatible model to be running.

What happens if the LLM is not available?

The QuantGen code generator and AI screener gracefully degrade. You'll see a structured error message indicating the LLM is unreachable. Non-AI workflows (manual backtests, non-AI screening, sector scanning, Markov scanning with cached models) continue to work normally.

How do I save my work?

  • QuantGen strategies — click "Save" or "Save As" in the Builder. They persist as .py files.
  • Screener results — auto-saved to browser localStorage (24h expiry)
  • Builder state — auto-saved to localStorage on every change
  • Backend models — Markov XGBoost/LSTM models are persisted to backend/models/markov/

How do I export data?

  • Sector stocks → QuantGen: "Export N Tickers" button
  • Screener results → QuantGen: "Export to QuantGen" button
  • PDF report: available after screener run (download button)
  • Strategy code: saved as .py files; copy from Monaco editor
  • Backtest results: viewed in Dashboard; stats JSON available in collapsible section
